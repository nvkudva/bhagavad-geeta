# Bhagavad Geeta PWA

A modern, high-performance Progressive Web App (PWA) for the Bhagavad Gita, designed with a premium reading experience in mind.

## Features

- **Modern UI**: Apple Glass inspired design with sleek aesthetics.
- **Multilingual Support**: Switch between English, Kannada, and Telugu easily.
- **Offline First**: Built as a PWA, ensuring it works flawlessly even without an internet connection.
- **Dark & Light Mode**: Seamlessly adapts to your preferred theme.
- **Fast & Responsive**: Built with Vite and React for a smooth experience.

## Tech Stack

- **Framework**: React with TypeScript
- **Bundler**: Vite
- **PWA**: Vite PWA Plugin
- **Styling**: Tailwind CSS / Vanilla CSS (Modern CSS features)

## Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/nvkudva/bhagavad-geeta.git
    cd bhagavad-geeta
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Run the development server**:
    ```bash
    npm run dev
    ```

4.  **Build for production**:
    ```bash
    npm run build
    ```

## Development

This project was developed with a focus on visual excellence and premium user experience.

- **Design System**: Follows modern web design practices including glassmorphism and subtle animations.
- **Data**: Verses and chapters are stored as JSON for fast access.
